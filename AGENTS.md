# Claude to Codex

## Git

- Trabalhar diretamente na branch main, conforme a instrução explícita do mantenedor.
- Não criar branches alternativas ou worktrees para este projeto.
- Fazer commits organizados por etapa e verificar o resultado antes de enviá-los ao GitHub.
- Não sobrescrever alterações remotas nem usar force push.

## Produto

- Construir um aplicativo local com janela própria, integrado ao Codex instalado na máquina do usuário.
- Preservar a função dos componentes convertidos do Claude Code; substituição textual não comprova compatibilidade.
- Não executar código do repositório de origem durante download, inventário ou conversão.
- Usar interfaces oficiais do Codex e preservar recuperação das instalações gerenciadas.
- Manter o README alinhado ao estado real: planejamento, implementação, testes e versões publicadas são estados diferentes.

A proposta inicial está em docs/superpowers/specs/2026-10-13-claude-to-codex-design.md.
