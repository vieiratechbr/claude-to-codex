# Claude to Codex v0.3.0-beta.1 — Windows

Beta pública para testes no Windows x64.

- Todas as skills encontradas vêm selecionadas, com **Instalar como pacote** ativo. Várias skills podem virar uma instalação com chamada única, como `$autor-repositorio`.
- A skill de entrada escolhe e combina as skills pertinentes à tarefa a partir de um catálogo. As chamadas individuais continuam disponíveis.
- Revisão e Histórico mostram chamadas extraídas do YAML, com botão **Copiar**. Instalações anteriores também recebem essa exibição quando seu pacote convertido está disponível.
- Atualizar um conjunto completo inclui novas skills da origem na revisão. Seleções parciais são preservadas; a chamada do conjunto permanece quando resta uma skill.
- Instalador com ícone, lateral e cabeçalho próprios. Na conclusão: **Iniciar o aplicativo**, link do projeto e **Apoiar github**, inicialmente desmarcado. Marcar e concluir abre o repositório; deixar estrela continua sendo uma ação manual.

Baixe `Claude-to-Codex-0.3.0-beta.1-Windows-x64-Setup.exe`. Requer Git e Codex com suporte a plugins locais; login no Codex para adaptação assistida. O instalador é por usuário e não tem assinatura digital.

O agrupamento preserva recursos, referências, licenças e impedimentos. Nomes de chamada repetidos no mesmo pacote bloqueiam instalação. Plugins completos diferentes devem ser importados separadamente ou ter suas skills internas selecionadas. Scripts, MCPs e ferramentas externas continuam exigindo dependências e testes próprios.

O teste com 74 skills usa uma origem artificial e comprova agrupamento e preservação de arquivos. Ele não atesta o funcionamento de qualquer coleção externa de 74 skills. Consulte [a validação](https://github.com/vieiratechbr/claude-to-codex/blob/main/docs/VALIDATION.md) para evidências e limites.
