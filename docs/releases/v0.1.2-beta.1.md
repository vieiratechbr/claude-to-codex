# Claude to Codex v0.1.2-beta.1

**Beta pública para testes com repositórios reais. Ainda não é uma versão estável.**

## Download

Baixe **Claude-to-Codex-0.1.2-beta.1-Windows-x64-Setup.exe** em Assets e execute o instalador. Instala por usuário, permite escolher a pasta e criar atalhos. Inclui o runtime do aplicativo; Git, Codex e dependências das skills são instalados separadamente.

O instalador não possui assinatura digital e pode exibir a verificação do Windows SmartScreen.

## Correções

- Leitura de objetos Git em lote e clone/fetch com história rasa, evitando milhares de processos e download do histórico inteiro.
- Links internos para arquivos são materializados com validação de destino, ciclos e orçamento, sem criar links no computador.
- Marketplace com `source: "./"` identifica o plugin da raiz sem criar um componente duplicado.
- Referências de scripts e recursos usam a pasta da skill; templates dinâmicos exigem arquivos correspondentes. Assets obrigatórios ausentes continuam bloqueados.
- Documentação e cópias de templates inativas não são tratadas como skills instaláveis.
- A adaptação assistida usa uma skill por chamada e edições de trechos únicos. Inclui uma tentativa de correção com feedback, preserva avisos e mantém limites de conteúdo.
- Blocos de comandos `bash` e avisos em prosa sobre variáveis indisponíveis deixam de causar bloqueios incorretos. Usos dessas variáveis dentro de comandos continuam sendo verificados.
- Importações por pasta recebem a identidade da origem completa; atualizações de instalações anteriores preservam seus nomes nativos e recuperação.

## Repositório real testado

**A skill principal UI UX Pro Max passou** na conversão, instalação reconhecida pelo Codex e três buscas reais: sistema de design, acessibilidade e React. Foram verificados 72 arquivos de recursos/licença por hash. Configuração pessoal preservada; instalação em perfil temporário.

Para usar esse repositório, cole `https://github.com/nextlevelbuilder/ui-ux-pro-max-skill` e preencha **Opções avançadas → Pasta** com `.claude/skills/ui-ux-pro-max`. Requer Python 3.

O pacote completo inclui outras seis skills e ficou bloqueado por agentes externos e workflows auxiliares sem adaptação confirmada. A aprovação da skill principal não se estende ao pacote inteiro. Revisão testada: `7246805992a42b7bba37d4cac83b01416f0c6c44`.

## Requisitos e limites

Windows x64, Git for Windows e Codex nativo com suporte aos comandos de plugins. Login e rede são necessários para adaptação assistida. O aplicativo foi desenvolvido e verificado com Codex CLI 0.157.1.

A skill `ui-ux-pro-max` requer Python 3 para suas buscas. O aplicativo não instala Python nem runtimes de terceiros automaticamente. Instalação reconhecida não comprova o funcionamento de todos os scripts, geração de imagens ou integrações das skills auxiliares.

Consulte [compatibilidade](https://github.com/vieiratechbr/claude-to-codex/blob/main/docs/COMPATIBILITY.md) e [validação](https://github.com/vieiratechbr/claude-to-codex/blob/main/docs/VALIDATION.md). A release anterior v0.1.1 também pertence à fase beta; seus downloads são preservados.
