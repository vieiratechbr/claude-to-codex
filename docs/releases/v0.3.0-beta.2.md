# Claude to Codex v0.3.0-beta.2 — Windows

Beta pública para testes no Windows x64.

- Corrige bloqueios indevidos de `user-invocable: true`, `model` e `allowed-tools`. Preferências são preservadas; modelo e permissões continuam sendo os da sessão Codex.
- Preserva skills manuais com a política nativa `allow_implicit_invocation: false`. A chamada geral do pacote não autoriza sua execução; use a chamada individual explícita.
- Distingue arquivos de projeto e saídas de assets de recursos que realmente deveriam estar no pacote. Recursos obrigatórios ausentes continuam bloqueados.
- Preserva documentos, especialistas e helpers compartilhados como contexto inativo, com um mapa de caminhos por skill. Não executa scripts nem ativa hooks durante importação.
- Tenta corrigir uma edição ambígua do modelo com feedback e identifica a skill afetada se a adaptação falhar. Mantém correspondência exata, limites e bloqueios reais.

**Claude Code Game Studios ainda não tem compatibilidade integral.** Na revisão testada, a `estimate` passou na conversão, instalação e verificação isolada. A `design-system` e o pacote completo continuam bloqueados por requisitos do framework ainda não portados, incluindo localização de scripts, controles de aprovação e medição de contexto. Esta beta não é uma liberação irrestrita das 74 skills. Nenhum script da origem foi executado.

Baixe `Claude-to-Codex-0.3.0-beta.2-Windows-x64-Setup.exe`. Requer Git e Codex com suporte a plugins locais; login no Codex para adaptação assistida. Instalador por usuário, sem assinatura digital.

Consulte [compatibilidade](https://github.com/vieiratechbr/claude-to-codex/blob/main/docs/COMPATIBILITY.md) e [validação](https://github.com/vieiratechbr/claude-to-codex/blob/main/docs/VALIDATION.md). Instalação reconhecida não comprova o workflow de cada skill ou integração externa.
