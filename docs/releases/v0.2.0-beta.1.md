# Claude to Codex v0.2.0-beta.1 — Windows

**Beta pública, ainda em testes.** Esta versão facilita escolher e testar uma skill dentro de um plugin do Claude Code.

## Melhorias

1. **Skills internas selecionáveis:** cole o link do repositório e escolha uma skill diretamente. O plugin completo continua disponível; a seleção evita importar o mesmo componente duas vezes. Templates inativos permanecem recursos.
2. **Revisão mais clara:** impedimentos aparecem primeiro, com a skill ou o arquivo afetado. É possível voltar para escolher skills separadamente; avisos ficam recolhidos.
3. **Adaptação com contexto:** o Codex recebe trechos relevantes de referências, scripts e auxiliares, dentro de limites declarados. Esse contexto é somente leitura; as edições continuam restritas à skill ativa.
4. **Verificar instalação:** confere reconhecimento, ativação, origem gerenciada e hashes no cache do Codex. Verifica Python 3 quando necessário e oferece um prompt para copiar. Não executa scripts importados.
5. **Aviso de novas versões:** consulta releases públicas, incluindo betas. O botão de download abre o instalador do próprio projeto no navegador; a atualização é manual.

Também corrige o retorno do Histórico para a seleção de uma origem diferente e usa o nome anunciado pela skill no prompt de teste.

## Verificação

Passaram a checagem de tipos, 142 testes automatizados, o ciclo real de instalação/atualização/recuperação/remoção em perfil Codex temporário, três testes desktop e a abertura da janela empacotada com Git fora do PATH. O teste nativo opt-in foi executado separadamente. Revisão independente concluída após correções com regressões.

Na revisão `7246805992a42b7bba37d4cac83b01416f0c6c44` da UI UX Pro Max, a interface apresentou sete skills. A principal foi selecionada sem preencher Pasta, adaptada com Codex autenticado e instalada em perfil temporário: 75 arquivos conferidos no cache nativo, 71 recursos/licença preservados e três buscas Python revisadas passaram nessa cópia. A repetição sequencial manteve a configuração pessoal igual em todos os checkpoints.

Esse resultado se aplica à skill principal e às consultas executadas. Os workflows das outras seis skills, MCPs externos e compatibilidade universal não foram confirmados. Os registros detalhados estão em `docs/VALIDATION.md` no repositório.

## Requisitos

- Windows x64, Codex nativo com suporte a plugins locais e Git em uma das localizações detectadas.
- Login no Codex para adaptação assistida e internet para baixar repositórios e consultar versões.
- Para a UI UX Pro Max, escolha **Skill: ui-ux-pro-max** após a análise; suas buscas exigem Python 3.

Instalador por usuário, sem assinatura digital. Não inclui Git, Codex ou dependências dos plugins. As versões antigas não consultam atualizações automaticamente: baixe esta beta para usar a nova função. O `SHA256SUMS.txt` permite conferir o download publicado.
