# Claude to Codex v0.1.1

Primeira release para download direto do aplicativo Windows. Importe skills e plugins compatíveis do Claude Code, revise a adaptação e instale no Codex da sua máquina.

## Download e instalação

Baixe **Claude-to-Codex-0.1.1-Windows-x64-Setup.exe** em **Assets**, abaixo, e execute o instalador. Ele permite escolher a pasta e criar atalhos. O aplicativo inclui seu próprio runtime.

Requisitos: Windows x64, Git for Windows e Codex instalado com suporte a plugins. Faça login no Codex para usar a adaptação assistida. Não é necessária uma chave de API separada. O instalador não inclui Git, Codex ou dependências de plugins importados.

## Recursos

- Análise de repositórios do GitHub sem executar scripts da origem.
- Seleção de skills e plugins, adaptação assistida opcional, revisão de arquivos e exportação ZIP.
- Instalação, atualização, remoção e recuperação de operações gerenciadas, com histórico local.
- Interface com mascote laranja do Claude, símbolo do Codex, quatro etapas visuais e opções avançadas recolhidas.

## Validação e limites

53 testes, ciclo nativo isolado de plugins, janela desktop, geração do NSIS e abertura do executável empacotado passaram na [validação Windows](https://github.com/vieiratechbr/claude-to-codex/actions/runs/38419589295). Os testes usaram perfis temporários; o assistente NSIS não foi executado na máquina pessoal. macOS e Linux ainda não foram validados.

Componentes sem equivalente podem bloquear a instalação. Scripts, MCPs e integrações importados podem exigir configuração e software próprios. Consulte [compatibilidade](https://github.com/vieiratechbr/claude-to-codex/blob/v0.1.1/docs/COMPATIBILITY.md).

O instalador não tem assinatura digital. O arquivo **SHA256SUMS.txt** permite conferir a integridade do download. A publicação calcula o checksum do instalador anexado à release.
