# Claude to Codex v0.1.2-beta.2 — Windows

**Beta pública, ainda em testes.** Esta atualização corrige o erro “Git não encontrado” ao abrir o aplicativo pelo Windows quando o Git está instalado fora do PATH.

## Correção

- Detecta o Git for Windows em instalações comuns por máquina e por usuário.
- Detecta o Git presente no runtime principal do Codex, sem depender do PATH preparado pelo terminal do Codex.
- Preserva a prioridade do executável explícito e do PATH; ignora diretórios com nome de executável e atalhos `.cmd`/`.bat`.
- Quando não encontra nenhuma instalação, orienta instalar o Git for Windows e reabrir o aplicativo.

O aplicativo não instala o Git nem altera o PATH do Windows.

## Verificação

O erro foi reproduzido na beta.1 com o PATH limitado a `Windows/System32`. Com a beta.2 e o mesmo ambiente, a janela empacotada detectou o Git 2.53.0.windows.3 e analisou o repositório `nextlevelbuilder/ui-ux-pro-max-skill`, pasta `.claude/skills/ui-ux-pro-max`, commit `7246805992a42b7bba37d4cac83b01416f0c6c44`.

Passaram a checagem de tipos, 99 testes automatizados, o ciclo isolado de instalação/atualização/recuperação/remoção no Codex, o fluxo desktop e o teste da janela empacotada sem Git no PATH. O teste nativo, opt-in na suíte comum, foi executado separadamente.

Esta rodada valida a detecção e a análise da origem. A aprovação funcional anterior continua restrita à skill principal UI UX Pro Max; o plugin completo permanece bloqueado por requisitos auxiliares não confirmados.

## Requisitos

- Windows x64, Codex nativo com suporte a plugins locais e Git disponível em uma das localizações detectadas.
- Login no Codex para adaptação assistida e internet para baixar repositórios.
- Para a UI UX Pro Max, selecione a pasta `.claude/skills/ui-ux-pro-max` em **Opções avançadas**; suas buscas exigem Python 3.

Instalador por usuário, sem assinatura digital. Não inclui Git, Codex ou dependências dos plugins. O `SHA256SUMS.txt` permite conferir o download publicado.
