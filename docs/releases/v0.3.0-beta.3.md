# Claude to Codex v0.3.0-beta.3 — Windows

Beta pública para testes no Windows x64.

- Amplia a conversão de coleções com documentos, helpers, especialistas e catálogos compartilhados. Conserva a chamada geral do pacote e as chamadas individuais.
- Adapta helpers reconhecidos com raízes separadas para projeto e recursos instalados, execução explícita e conferência de hashes. Requer Python 3 e GNU Bash para esses helpers.
- Preserva modos, escolhas, consentimento, gates, checkpoints e recuperação. Especialistas recebem bindings e procedimento de configuração explícita; não são ativados silenciosamente.
- Separa instruções operacionais, dados de avaliação e proveniência. Catálogos e resultados mutáveis usam uma cópia de trabalho aprovada no projeto; os recursos instalados permanecem somente leitura.
- Isola a conversão assistida da configuração pessoal, valida o cache pelo conteúdo completo e permite retomar adaptações aprovadas. Falhas globais de login, cota ou configuração deixam pendências explícitas.
- Corrige falsos bloqueios em chamadas de helpers, exemplos Markdown, metadados, caminhos e referências. Dependências reais ausentes e funções obrigatórias sem adaptação continuam bloqueadas.

## Claude Code Game Studios

Revisão testada: `05ad7c8a5b8aa2aa86bbd3439ae7cf7295cac418`, com 74 skills, 49 especialistas e 123 especificações. **Conversão completa aprovada, sem impedimentos:** 75 chamadas, 724 arquivos, cinco políticas manuais preservadas e nenhum link local ausente. Instalação, hashes, listagem das 75 chamadas e remoção passaram no Codex real em perfil temporário, com configuração pessoal inalterada. A chamada geral é `$donchitos-claude-code-game-studios`. Os resultados estão em [VALIDATION.md](https://github.com/vieiratechbr/claude-to-codex/blob/main/docs/VALIDATION.md).

A instalação não executa automaticamente as 74 tarefas do framework. Especialistas, permissões, telemetria e ferramentas externas exigem preflight no projeto real. Hooks da origem não são ativados ao importar somente skills. Scanners exclusivos do formato Claude produzem um fallback explícito `not run` com procedimento de auditoria nativa, sem aprovar controles não testados.

Baixe `Claude-to-Codex-0.3.0-beta.3-Windows-x64-Setup.exe`. Requer Git, Codex com plugins locais e login para conversão assistida. Instalador por usuário, sem assinatura digital.
